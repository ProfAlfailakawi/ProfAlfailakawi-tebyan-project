# Evidence Mode — Setup & Activation

منظومة الإسناد (Evidence Mode) تحوّل Oracle / QawlFasl / Knowledge Center من
"إجابة نموذج" إلى "إجابة مُسندة" بمصدرها (قاعدة تبيان / الويب الحالي) + استشهادات
+ درجة ثقة، عبر Gemini File Search و Google Search Grounding.

التصميم **آمن الفشل (fail-safe)**: كل مسارات الإسناد اختيارية (opt-in) وتسقط
تلقائيًا إلى السلوك القديم عند أي خطأ أو غياب إعداد. المسار الافتراضي المحمي في
`functions/index.js` و `server.ts` **لم يُمَس**.

## المعمارية
- `functions/aiCore.cjs` — المصدر الوحيد المشترك (يستورده الاثنان: الدالة و server.ts).
  ينهي ازدواجية الكود، ويحتوي منطق الإسناد عبر REST + fetch (نفس نمط TTS الحالي،
  بلا SDK جديد وبلا مخاطرة على المسار المحمي).
- الإسناد يُفعَّل فقط عندما يرسل العميل `config.evidenceMode` = `internal | web | auto`.
- الاستجابة تُوسَّع إلى `{ text, evidence: { source, confidence, citations[] } }`
  (متوافقة رجعيًا؛ العملاء القدامى يقرؤون `.text` فقط).

## خطوات التفعيل (مرة واحدة)
1. **بناء المخزن ورفع القاعدة**:
   ```bash
   GEMINI_API_KEY=xxxx node scripts/provisionFileSearch.mjs
   ```
   يطبع اسم المخزن، مثل `fileSearchStores/abc123`.

2. **ربط المخزن بالـ runtime** — أضِف المتغيّر في بيئتَي الباك-إند:
   - Cloud Function `api` (env): `TEBYAN_FILE_SEARCH_STORE=fileSearchStores/abc123`
   - dev/backup: نفس المتغيّر في `.env` الذي يقرأه `server.ts`.

3. **انشر** كالمعتاد (البند 11 في AGENTS.md):
   ```bash
   npm run deploy
   ```

## اختبار سريع
- افتح **قول فصل** → أي سؤال → زر «تحقّق من إسناد تبيان» → يظهر شارة المصدر + المصادر.
- افتح **المستشار الكلي** → فعّل «قاعدة تبيان» أو «الويب الحالي» ثم شغّل.
- افتح **مركز المعرفة** → تبويب «استناد المعرفة».

بدون خطوة (1) + (2): كل شيء يعمل كالسابق، والشارة تعرض «اجتهاد عام» (source=model).

## ملاحظات صدق هندسية
- لم يُختبر مسار File Search على Gemini حيًا في بيئة التطوير هذه (لا مفتاح/شبكة).
  المطلوب بعد النشر: تشغيل الاختبار السريع أعلاه مرة واحدة والتأكد من ظهور الاستشهادات.
- File Search و Search Grounding لهما **تكلفة فوترة منفصلة لكل استعلام** (لا يغطيها
  اشتراك Google AI Pro). لذلك الإسناد اختياري وليس افتراضيًا في كل نداء.
- لم تُضَف Gemini Live (الصوت الحي) عمدًا: لا تتوافق مع Cloud Functions/Hosting
  (WebSocket طويل الأمد)، وتتطلب Cloud Run مخصصًا — مؤجَّلة.
- أسماء دوال File Search في الـ SDK (سطر `// [SDK]` في السكربت) قد تختلف حسب إصدار
  `@google/genai`؛ عدّلها في مكان واحد إن لزم.
