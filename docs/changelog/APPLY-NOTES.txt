حزمة فروق تبيان فقط — بلا مجلد wrapper وبلا dist أو node_modules أو أسرار.

السبب الجذري:
كان رأس الصفحة يملك canonical وOpen Graph جيدين، لكن جسم HTML قبل JavaScript كان مجرد root فارغ؛ لذلك لا يجد الفاحص النصي أو بعض الزواحف محتوى دلالياً. أضيفت صفحة هبوط HTML حقيقية داخل root يستبدلها React فور الإقلاع، مع WebSite/WebApplication Schema وrobots.txt وsitemap.xml وتنسيق هادئ مستقل.

ملاحظة فحص:
البناء الإنتاجي وفحص TypeScript ناجحان. ملف CustomerSite.tsx غير مستخدم ويعتمد وحدات غير موجودة، لذلك استُبعد من فحص التطبيق الفعلي من دون حذفه أو حذف أي ميزة تشغيلية.

لم يُنفذ أي رفع أو نشر.
